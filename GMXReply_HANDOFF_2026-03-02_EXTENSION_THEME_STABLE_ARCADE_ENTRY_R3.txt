What was actually fixed in this pack
1) Extension reload / jitter issue reduced hard
- extension/site_sync.js previously wrote to chrome.storage.local every 4 seconds even when nothing changed.
- That constant write churn triggered popup refresh logic again and again.
- Now site_sync first compares current values vs stored values and SKIPS storage writes when nothing changed.
- Result: popup / quick panel should stop constantly reloading their own state when the site is idle.

2) Extension theme sync made real (and stable)
- site_sync now syncs these site values into extension storage too:
  - gmx_ext_theme
  - gmx_theme
- popup.js now reads those theme keys.
- popup / quick panel now load extension/themes.json and apply the chosen theme colors to the UI by CSS variables.
- If anything is missing, it safely falls back to classic/dark.

3) Popup refresh logic made lighter
- popup.js no longer does a full snapshot refresh for every last-copied text change.
- Preview text updates locally without unnecessary API churn.
- Theme updates now re-skin the popup without forcing usage snapshot fetches.
- Auth/base changes still do a real snapshot refresh.

4) Arcade entry added in extension UI
- Added Open Arcade button in:
  - extension/popup.html
  - extension/quick.html
- popup.js binds that button to /arcade on the current GMXReply base.
