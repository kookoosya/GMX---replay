WHAT WAS CHANGED
1) Arcade route was rebuilt into a lighter play-first page.
- Replaced the huge Phase 53-style management / migration / Supabase-heavy ArcadePage shell with a direct gameplay-first shell.
- The route now prioritizes playing, not internal scaffolding.
- Result: the Arcade tab should feel much less bloated.

2) 5 core games are now surfaced clearly and immediately.

  - Neon Strike
  - Payload Lab

  - Boss Vault

3) All 25 React games are now directly accessible on the same route.
- The page now exposes the full 25-game React library as a real selectable grid.

- This directly addresses the “there should be 25 games” complaint in the route UX.

4) Games now lazy-load instead of front-loading the entire arcade bundle.
- ArcadePage no longer eagerly imports every single game module on first paint.
- Each selected game is loaded only when the user opens it.

5) The playfield is now single-focus.
- Only the currently selected game module mounts in the playfield.
- The page still gives access to all core + React games, but only the active module is mounted.
- This avoids the old “too much stuff at once” feeling.

6) Shared local ladders are still visible.
- The leaderboard panel remains on the page.
- Runtime status updates still react to local arcade events.
