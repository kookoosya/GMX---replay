What I fixed in this pack (R37)

A) Wallpaper + Theme lag removal (site)
1) Removed the biggest UI freeze after picking a wallpaper
- Before: clicking a wallpaper called renderWallpaperUI() which rebuilt the whole grid + re-triggered image loads.
- Now: click only updates localStorage + toggles .active on existing cards via markWallpaperSelection().

2) Added prefetch + decode for smoother first paint
- Added prefetchImage(url) cache.
- On wallpaper cards: pointerenter prefetches the full image.
- On click: apply waits for prefetch promise to finish (usually instant after hover), avoids jank.

3) Added real thumbnail pipeline for webp wallpapers
- Generated lightweight thumbs:
  - assets/wallpapers/thumbs/v2_*.webp
  - assets/wallpapers/thumbs/v3/site/v3_*.webp
  - assets/extbg/thumbs/extv3_*.webp
- Site wallpaper grid uses thumbs for v2/v3, SVG stays as-is.
- Extension wallpaper grid uses thumbs for extv3.

4) Simplified background CSS usage (less repaint risk)
- --bg_wall / --bg_user now store only url("...") instead of full "center/cover ... fixed" strings.
- app.css now defines background-repeat for all layers.

5) Reduced chunk size for grid rendering
- wpGrid chunk: 18 -> 12
- extWpGrid chunk: 18 -> 12

B) Extension popup wallpaper correctness + speed
1) Popup wallpaper options now match site IDs (no mismatched mapping)
- Added options:
  - ext_free_01 / ext_free_02
  - extv3_41..57
  - ext_03..43
- Default is ext_free_01.

2) normalizeExtWallpaperId fixed
- No longer rewrites ext_free_XX or ext_XX into extv3_XX.
- Keeps canonical site IDs.

3) Popup wallpaper prefetch
- resolveWallpaperSource() now calls prefetchWallpaper(finalUrl) to warm cache.

C) Arcade scaffold cleanup (no unwanted seeded games)
1) Removed bundled default games
- frontend/src/features/arcade/externalPortalCatalog.ts:
  - DEFAULT_EXTERNAL_PORTAL_GAMES is now empty by design.
  - Arcade is “add your own link -> tile appears” only.

2) Arcade page copy + empty states
- frontend/src/pages/ArcadePage.tsx:
  - neutral header text
  - shows explicit empty-state messages when free/pro lists are empty.
