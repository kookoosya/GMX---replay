GMXReply — HANDOFF R55 (RU)

Источник правды:
- база = текущий рабочий архив пользователя с cumulative-слоями до R54
- этот R55 = recovery/safe pack после неудачного R54 taste-pass

Что сделано
- Убран рискованный GM/GN English generation-проход из R54, который давал мусорные массовые обращения и кривые хвосты.
- English GM/GN generation переведён на более безопасный singular-reply режим:
  - ответы одному человеку
  - без group-tone
  - без Pepe / army / soldier / frens / we outside / we up / anon / captain / sunshine
- `min` снова жёстко зажат по длине и ориентирован на короткие строки с emoji.
- `mid/max` собраны из безопасных singular vocatives + curated reply tails вместо старой мусорной склейки.
- Усилен hard-ban для кринж/мусорных слов и хвостов.
- Фронтенд-файлы из стабильного слоя R53 добавлены в архив как safe alignment layer.

Что не сделано
- Это не финальный идеальный taste-pass.
- Не проведена полная ручная зачистка каждого vocative по вкусу пользователя.
- Внешний AI fallback не подключался.

Что проверить после накатки
1. Сайт снова должен нормально открываться и реагировать.
2. Проверить:
   - GM ordinary min
   - GN ordinary min
   - GM crypto min
   - GN crypto min
   - потом mid/max
3. Проверить Batch 10 и Quick 1.
4. Отдельно проверить, что больше не пролезают:
   - soldier
   - army
   - frens
   - Pepe
   - we outside / we up
   - captain / sunshine / anon
5. Проверить, что min реально короткий и с emoji.

Если чат умрёт
- Следующий шаг = точечный whitelist-pass по словарю обращений.
- Работать только поверх текущего живого архива пользователя.
- Не переписывать generation заново.
- Не трогать Arcade / платежи / security.
- Делать один cumulative zip.

Примечание
- Сообщение в браузерной консоли про React DevTools не является фатальной ошибкой само по себе.
- Если после накатки сайт всё ещё не отвечает, смотреть реальную runtime/server ошибку отдельно, а не строку про DevTools.
