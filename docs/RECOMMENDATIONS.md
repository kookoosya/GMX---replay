### Arcade
- Удалены игры без реальных обложек (GameDistribution, битые embeds)

## Идеи для «вау»-эффекта и монетизации

### 1. **Arcade — геймификация**
- **Достижения в играх** — «сыграл 10 игр», «победил в Zombs Royale» → бейджи в профиле
- **Турниры** — еженедельные лидерборды по конкретным играм, топ-3 получают PRO на неделю
- **«Игра дня»** — одна игра в день на главной, +бонусы при игре
- **Streak** — «играл 5 дней подряд» → скидка на PRO

### 2. **Pro — явная ценность**
- **Exclusive games** — 5–7 топовых игр только для PRO (Shell Shockers, 1v1.LOL, Kour.io уже есть)
- **Без рекламы** — убрать рекламу в embeds для PRO
- **Fullscreen+** — полноэкранный режим без лишних UI
- **История сессий** — «вчера играл 47 мин в Smash Karts» в личном кабинете

### 3. **Первые впечатления (landing)**
- **Hero video** — 10–15 сек ролик: «Reply на email, играй в игры» на тёмном фоне
- **Один клик = demo** — кнопка «Попробовать» сразу открывает реплей-демо без регистрации
- **Trust badges** — «50K+ писем обработано», «игры от CrazyGames»

### 4. **Расширение**
- **Быстрый запуск** — горячая клавиша (Ctrl+Shift+G) → панель с последними 3 играми
- **Уведомление «Игра дня»** — раз в день toast: «Geometry Dash — попробуй сегодня»
- **Офлайн-кэш** — 3–5 любимых игр доступны без интернета (Service Worker)
- **Интеграция в Gmail/Outlook** — кнопка «Play» рядом с письмом, если в нём ключевые слова (игры, arcade)

### 5. **SEO и рост**
- **Страницы по играм** — `/arcade/agario`, `/arcade/geometry-dash` с описаниями и ссылкой «Play»
- **Blog** — «Топ-10 .io игр 2025», «Как играть в Agar.io» — трафик на сайт
- **Referral** — «Приведи друга → неделя PRO бесплатно»

### 6. **Технические улучшения**
- **Preload популярных игр** — Agar.io, Slither.io загружать в фоне при открытии Arcade
- **PWA** — «Добавить на главный экран» для мобильных
- **Темы** — не только обои, но и цветовые схемы (dark/light/AMOLED)

### 7. **Монетизация**
- **Freemium** — бесплатно 5 игр в день, без лимита для PRO
- **Подписка** — monthly/yearly со скидкой на год
- **One-time unlock** — «разблокировать Arcade навсегда» за фикс. сумму
