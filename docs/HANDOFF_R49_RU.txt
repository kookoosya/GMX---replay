GMXReply — HANDOFF R49 (RU)

Источник
- База для правок: текущий R47 full working baseline пользователя
- R48 transition pack использован только как docs / target spec

Что сделано
- Переписан English generation quality block в Backend/index.js под real X-style GM/GN replies
- Убран дневниковый / sign-off тон из английской ветки генерации
- Добавлены curated reply banks для GM/GN с нормальной лексикой X: legend, degen, ser, my g, mate, dear, builder и т.д.
- Стили сведены в понятные семейства: ordinary / crypto / builder / warm / calmer / playful
- Сохранена совместимость со старыми style keys: classic, degen, alpha, builder, calm, classy, focus, cheer, meme, emoji, minimal, noemoji
- Добавлен fingerprint dedupe поверх exact-text dedupe
- Добавлен global anti-repeat по recent_replies по kind
- Bulk generation пути переведены на ranked candidate generation вместо простого random loop
- Обновлены user-facing style/preset labels и guide copy под real X replies
- Почищены Best/GM/GN hints, чтобы они соответствовали новой логике

Что НЕ делалось
- Не трогались Arcade / payments / security / post-auth deep backend хвосты
- Не менялись quotas / referrals / promoter logic
- Не подключался внешний AI provider
