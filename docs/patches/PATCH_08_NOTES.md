# PATCH_08_LANG_FIX

## Что исправлено
- В `frontend/src/legacy/legacyApp.ts` ограничен `patchDynamicCopy()` только для `en` и `ru`.
- Для остальных UI-языков (de/fr/es/pt/it/nl/tr/pl/id/uk) больше не перезатираются переводы английским текстом на вкладках, где применялись динамические подмены.

## Почему это ломало перевод
- Сначала `applyLang()` правильно накладывал переводы из `I18N`.
- Потом `patchDynamicCopy()` поверх этого насильно подставлял только EN/RU-копию для части блоков (`Home`, `Themes`, `Extension Themes`, `Upgrade Pro`).
- В итоге многие языки выглядели частично переведёнными, а часть вкладок снова становилась английской.

## Что проверить
- Запустить `npm run dev`
- На `http://127.0.0.1:5173/app` переключить UI-языки `de`, `fr`, `es`, `uk`
- Проверить вкладки `Home`, `Themes`, `Extension Themes`, `Upgrade Pro`
