GMXReply — HANDOFF R52 (RU)

Что сделано

1. Жёстко вычищен англоязычный GM/GN generation block в Backend/index.js.
- Убраны кривые хвосты и нелепые конструкции, из-за которых вылезали строки в духе:
  - market owes us one
  - bags wake up green
  - tape looks polite already
  - hope the feed keeps its manners
  - feed / desk / room / brain / goblin nonsense
- Generation сдвинута в сторону более X-native reply-форм:
  - gm legend
  - gm ser, have a good one today
  - morning my g, good luck on the charts
  - gn legend, sleep well
  - gn degen, see you at first candle
  - rest before the next ship

2. Пересобраны curated English банки.
- Обновлены reply banks для:
  - GM ordinary / crypto / builder / warm / calmer / playful
  - GN ordinary / crypto / builder / warm / calmer / playful
- Расширены обращения, но без ухода в мусор:
  - legend
  - degen
  - ser
  - my g
  - mate
  - bro / brother
  - fam / gang
  - king / chief / boss
  - builder / dev / shipper / operator / founder
  - warm-ветка отдельно допускает queen / babe / twin

3. Упрощён сам composeEnglishReply.
- Теперь generation не лепит длинные 3-4 кусочные конструкции.
- Сильнее держится X-reply shape:
  - greet
  - greet + address
  - greet + short tail
  - greet + short wish
  - greet + one stronger mid-tail
- То есть output стал короче, прямее и ближе к reply, а не к странной мини-прозе.

4. Ослаблена ложная "вариативность" и усилен смысловой фильтр.
- replyQualityScore теперь штрафует кринжевые слова и shape’ы:
  - feed
  - timeline
  - desk
  - room
  - brain
  - app
  - goblin
  - manners / polite / honest
  - workable / usable
  - owes us one
  - wake up green
- За счёт этого ranked generation вытесняет странные строки вниз.

5. Дедуп/shape для обращений сохранён.
- fingerprint по-прежнему схлопывает простую замену обращения как fake variety.
- Добавлены queen / babe в нормализацию обращений.

6. Дополнительно подчищены адреса.
- ordinary/calmer больше не раздуваются queen/twin как базовой нормой.
- crypto убран bagholder как обычное обращение.
- Если greet = gmgm / gm gm / gn gn и одновременно есть address, generation теперь нормализует это до gm / gn, чтобы не получалось:
  - gm gm legend
  - gn gn mate

Что НЕ сделано

1. Я не подключал внешний AI fallback.
- Это сознательно.
- Сначала нужно было убрать кривое ядро generation.
- Подключать free AI как core сейчас нельзя: нестабильность, rate limits, дрейф качества.

2. Я не трогал Arcade / payments / security / прочие хвосты.
- Работа шла строго по generation quality block.

3. Я не правил site/app copy в этом паке.
- Этот R52 — именно backend generation cleanup.

Что проверить

1. GM / GN на сайте
- Quick 1
- Batch 10
- Best
- ordinary / crypto / warm / calmer / builder
- sizes: Fast / Balanced / Full

2. Смотреть именно на смысл строк.
- Не должно быть бреда про feed / room / manners / polite tape / market owes us one
- Не должно быть ощущения personal diary / sign-off essay
- GM/GN должны ощущаться reply к чужому X-post

3. Проверить Batch 10 и несколько повторных запусков подряд.
- Должны быть заметно живее обращения и shape
- Простая подмена обращения не должна доминировать
