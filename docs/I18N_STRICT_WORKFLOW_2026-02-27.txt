GMXReply i18n strict workflow

1) Add new UI text in EN.
2) Add locale overrides through mergeI18nPatch({...}) instead of raw top-level Object.assign loops.
3) Runtime now normalizes every locale against EN, so no tab/subtab can break because of a missing key.
4) Run: npm run audit:i18n
   - structural mode: fails on missing/type/array issues
   - strict text mode: node tools/i18n_audit.js --strict-text
     this also fails if any locale still inherits EN text
5) If a locale inherits EN, the UI stays whole, but that specific string still needs a real translation.
