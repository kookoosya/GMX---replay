# GMXReply — ревизия архива (CLEAN)

## Что это за архив
Это “чистая” сборка из Bac.zip: всё, что нужно для запуска проекта, но без секретов, временных файлов и мусора.

## Что удалено специально (чтобы не ломать тебе жизнь)
- `.env` и любые `.env.bak_*` (там могли быть секреты Supabase / платежей)
- `cookies*.txt`, `backend.log`, `logs/*.log`
- `data.sqlite-wal`, `data.sqlite-shm` (временные файлы SQLite)
- странная дублирующая папка с именем вида `#U041d...` (лишняя копия .env.example)

## Что оставлено (важно)
- `data.sqlite` — чтобы SQLite fallback продолжал жить (и чтобы можно было сравнивать данные при миграции)
- `frontend/src/legacy/legacyApp.ts` — НЕ трогал
- `.git` — оставил (удобно, если тебе нужен diff/история). Если хочешь “совсем чисто” — можно удалить.

## Как запускать (Windows PowerShell, Node v22)
1) В корне:
   - `npm install`
   - `npm --prefix frontend install`
2) Запуск dev:
   - `npm run dev`
3) URLs:
   - Backend: http://127.0.0.1:10000
   - Vite UI: http://127.0.0.1:5173/
   - Legacy bridge: http://127.0.0.1:5173/app

`SIGINT_RECEIVED / PROCESS_SHUTDOWN` при Ctrl+C — это нормальная остановка.

## Точки риска (где проще всего всё сломать)
- `frontend/src/legacy/legacyApp.ts` — любое “массовое улучшение переводов” может уронить i18n/объекты языков
- Payments/Billing verify — нужно делать “по-взрослому” (intent + nonce + wallet binding + on-chain checks)
- Extension session — токен не должен ротироваться сам по себе без явного rotate=1

## Мусор/долги, которые лучше оформить как бэклог, а не “чинить наугад”
- Vite warnings `Duplicate key ...` из legacy i18n:
  - лучше подавлять на уровне сборки/логгера (vite/plugin) или аккуратно дедупать *только* после автотеста и сравнения объектов.
- Неполные переводы в legacy UI (местами английские куски) — это может быть “как задумано”, чинить только точечно.

## Рекомендация по workflow (чтобы ты не страдал)
- Любые правки только ZIP-патчами: ты распаковываешь поверх и запускаешь
- На каждый патч: короткий smoke-checklist (2–5 команд) + что реально проверено
