GMXReply — текстовые отчёты и снимки (не автосборка)

Использование
  - I18N_SYNC_REPORT.txt — снимок после npm run i18n:sync; перегенерировать при смене ключей.
  - tools/wallpaper-audit-report.txt — вывод wallpaper-аудита; см. npm run wallpapers:audit
  - docs/WALLPAPER_*.txt — пайплайны/инвентарь обоев (ручное сопровождение)
  - docs/patches/*_SMOKE.md — чеклисты патчей

Если дата в файле старая — перезапустите соответствующую команду и закоммитьте новый отчёт.
