GMXReply — HANDOFF R54 (RU)

Что сделано

1. Пересобрана English GM/GN generation-ветка в Backend/index.js под singular direct replies к одному человеку
2. В generation добавлен жёсткий hard-ban для мусорных/неподходящих паттернов:
   - frens / army / soldiers / gang / everyone / y'all
   - Pepe / Wojak / holy trinity
   - we outside / we up / we all
   - reporting for duty / mission rest
   - часть мемно-массовых и self-post конструкций
3. Min теперь снова реально min:
   - короткие строки
   - emoji остаются
   - фильтр длины для min ужат
4. Mid/Max больше не подмешивают bare short-lines как основной каркас
   - для min остаются очень короткие формы
   - для mid/max каркас смещён в tail-based direct replies
5. Английские direct banks теперь строятся из safe singular vocab + safe direct tails
6. Сохранён большой объём вариаций для batch/anti-repeat сценариев, но без старой ебаты с feed/open/Pepe/army/soldier/frens

Что сознательно вырезано/зажато

- soldier / soldiers
- army
- frens / friends как direct plural address
- Pepe / Wojak
- group-address и not-a-reply конструкции
- массовые “we all / together we / mission / reporting” формы
