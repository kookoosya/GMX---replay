BASELINE
- Делалось поверх Bac 2 + последних правок до R15 (perf unlock/pause).
- Этот zip содержит ТОЛЬКО файлы на замену.

ЧТО СДЕЛАНО В R16 (главное – лаги themes/wallpapers)
1) Themes / Wallpapers (site) и Extension Themes / Wallpapers (site → sync) теперь имеют:
   - Search (по имени/id/ноте)
   - Paging “Show more (…)” (по 24 карточки за страницу)
   => это резко уменьшает DOM и сокращает фризы при открытии таба и скролле

2) “Только активная панель держит тяжёлый DOM”
   - При переключении Theme/Wall/Custom в Themes tab: очищаем innerHTML неактивных гридов
   - При переключении Theme/Wall/Custom в Extension Themes tab: очищаем innerHTML неактивных гридов
   => скрытые гриды больше не висят в памяти и не дёргают layout

3) Referral stats auto-refresh пауза в тяжёлых табах
   - В public/app.js добавлен REF_STATS_PAUSED + setRefStatsPaused()
   - showTab() уже ставит паузу для themes/extthemes (и возобновляет после выхода)
   => меньше лишних перерисовок во время выбора тем

4) Мелкая оптимизация выделения выбранной темы/обоев (extension)
   - markExtThemeSelection / markExtWallpaperSelection: O(1) (не проход по всем карточкам)
   - добавлен data-theme-id на карточки extension themes

   - переключение Theme/Wall/Custom не должно вызывать 5-минутный фриз
3) Открыть вкладку Themes → Wallpapers:
   - также Search + paging

   - следующий шаг: по скрину/по DOM-id точно выпиливаем лишние блоки из public/app.html + i18n ключи (комплексно)

C) Генерация:

D) Security/anti-tamper (Render/Vite/оплата/кошельки):
