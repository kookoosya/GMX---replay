Продолжаем GMXReply (R9) — приоритет: сильные лаги во вкладке Extension Themes / Wallpapers.

BASELINE (source of truth): Bac 2.zip (рабочий архив пользователя)
Overlay: этот cumulative pack содержит только файлы на замену + этот handoff.

Что сделано (R9)

1) Сайт: Extension Themes / Wallpapers — убрали тяжёлые перерисовки при частых refreshRefStats()
- Файлы:
  - public/app.js
  - frontend/src/legacy/legacyApp.ts
- Проблема:
  - refreshRefStats() часто вызывал renderExtThemes() (и иногда renderExtWallpapers()), которые каждый раз полностью пересобирали грид карточек.
  - На больших сетках это ощущается как "люто лагает".
- Решение:
  - Добавлен лёгкий memo/signature guard для renderExtThemes() и renderExtWallpapers():
    - если (lang/pro/unlocked/total) не изменились и грид уже отрендерен, мы НЕ пересоздаём DOM,
    - вместо этого только обновляем active-карточку + статусный текст.

2) Сайт: выбор темы/обоев — ускорили highlight активной карточки
- Файлы:
  - public/app.js
  - frontend/src/legacy/legacyApp.ts
- Проблема:
  - markExtThemeSelection()/markExtWallpaperSelection() делали forEach по всем карточкам на каждый клик (O(N)).
- Решение:
  - Теперь это O(1): снимаем active с текущей .active и ставим active только выбранной карточке через querySelector.

3) CSS: дополнительный буст производительности рендера карточек
- Файл:
  - public/app.css
- Решение:
  - добавлено content-visibility:auto + contain-intrinsic-size для .themeCard и .wpCard
  - это снижает стоимость рендера/скролла больших гридов в Chrome.

Что НЕ трогали
- Extension остаётся safe copy-only (никакого DOM-inject в X, никаких GM/GN кнопок внутри X)
- Backend / Supabase / Render deployment не трогали
- Arcade не трогали

Как проверить (чеклист)
1) npm run dev
2) В сайте открыть вкладку Themes → Extension Themes:
   - кликать по темам быстро подряд (10–20 кликов)
   - переключать Theme/Wall/Custom внутри Extension Themes
   - наблюдать: клики должны ощущаться легче, без "залипания" на секунды
3) Нажать Load stats в Referrals несколько раз (и/или подождать авто refresh):
   - Extension Themes грид НЕ должен полностью моргать/пересоздаваться каждый раз
   - активная карточка должна оставаться корректной
4) Переключить язык UI сайта:
   - грид может пересобраться 1 раз (это нормально, подписи LOCKED зависят от i18n)
   - дальше — снова без постоянных полных перерендеров при обновлении stats

Если лаги всё ещё сильные (следующий шаг)
- Проверить в DevTools Performance:
  - не спамит ли где-то renderExtThemes()/renderExtWallpapers() помимо refreshRefStats()
  - нет ли бесконечного цикла extSyncNow → site_sync → storage → перерендер UI
- Если упирается в SVG превью:
  - можно будет добавить более агрессивную lazy-load стратегию (например, грузить thumbs только когда панель видима)
