WHAT WAS BROKEN NOW
1) X inline GM/GN could disappear after the last dock-right pass
- The dock-right absolute placement could end up clipped/off-screen on some live X DOM variants.
- Result: buttons looked like they were missing.

2) X insert could fail silently
- The insert flow relied too heavily on one guessed contenteditable node plus execCommand insertText.
- If X changed which inner node is the real editable target, clicking GM/GN could do nothing even when the bar was visible.

WHAT WAS FIXED IN THIS PACK
1) STRONGER COMPOSER DETECTION
- File: extension/content.js
- Added broader editable-node discovery for X composers.
- The script now resolves the active editable child more reliably instead of only trusting a single div[role="textbox"] match.
- Composer lists are now ranked and deduplicated before binding the toolbar.

2) STRONGER INSERT PIPELINE WITH VALIDATION + RETRY
- File: extension/content.js
- Reworked setTextboxText() into a multi-step insert flow:
  - resolve real editable target
  - clear composer safely
  - try full insert in one pass
  - fallback to human-like typing
  - fallback to direct DOM write
- Insert now verifies that the expected text is actually present after writing.
- If the first bound composer went stale during X re-render, the script re-finds the current composer and retries once.
- If text still is not present, the action now fails loudly in code instead of silently pretending success.

3) MORE STABLE INLINE PLACEMENT NEXT TO NATIVE REPLY
- File: extension/content.js
- Added an inline-row placement mode before the previous dock-right fallback.
- First choice now: insert GM/GN directly into the same action row, immediately before the native Reply/Post button cluster.
- If that row variant is not suitable, only then it falls back to dock-right.
- If dock-right would render off-screen or misaligned, it falls back below the composer instead of disappearing.

4) EXTENSION VERSION BUMP
- File: extension/manifest.json
- Version bumped to 1.0.11 so the repaired build is easy to distinguish after reload.
