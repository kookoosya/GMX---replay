GMXReply — HANDOFF (RU) — 2026-03-04 — R34 Theme Self-Contained + Bridge Sync

Source of truth

Этот архив уже собран как один самодостаточный root `Backend/`.
Внутри теперь есть:
- `Backend/frontend/`
- `Backend/assets/`
- `Backend/public/assets/`

То есть больше не нужен отдельный перенос `frontend.zip` / `assets.zip`.

Что сделано сейчас

1) Самодостаточная структура
- Встроен `frontend/` внутрь `Backend/`
- Встроен `assets/` внутрь `Backend/`
- Ассеты продублированы в `Backend/public/assets/`, чтобы legacy `/app` видел обои и extbg напрямую

2) Legacy site runtime (`Backend/public/app.js`)
- Возвращены актуальные unlock-константы:
  - Themes = 8
  - Wallpapers = 8
  - Extension Themes = 4
  - Extension Wallpapers = 4
- Возвращена актуальная referral-формула (+1 каждые 3, потом +1 каждые 4)
- Починен критический сломанный блок `EXT_POPUP_TABS` (туда были случайно влиты объекты обоев)
- `THEMES`, `EXT_THEMES`, `EXT_WALLPAPERS` синхронизированы с legacy source
- `THEMES` / `EXT_THEMES` / `EXT_WALLPAPERS` режутся до 60
- Добавлены multi-path fallback’и для site/ext wallpaper asset paths:
  - `/assets/...`
  - `/bridge/assets/...`
  - v3 fallback для ext wallpapers
- Уменьшен лаг в Extension Themes:
  - очищаются неактивные heavy grids при переключении tab view
  - более лёгкое переключение active-card без полного перебора всех карточек
  - background-image для extension wallpaper thumbs ставится deferred батчами

3) Frontend legacy public copy (`Backend/frontend/public/app.js`)
- Те же правки, что и в `Backend/public/app.js`, чтобы public copy не расходилась с live legacy runtime

4) Extension popup (`Backend/extension/popup.js`)
- Popup переведён на canonical wallpaper IDs:
  - `ext_free_01`
  - `ext_free_02`
  - `ext_03 ... ext_60`
- Старые `extv3_XX` автоматически маппятся в canonical IDs
- Добавлен обратный legacy fallback при резолве картинок, чтобы старые webp тоже подхватывались
- Расширен список wallpaper options до 60
- Резолв путей теперь пробует:
  - `/assets/extbg/...`
  - `/bridge/assets/extbg/...`
  - legacy `extv3_XX`
  - legacy `/assets/wallpapers/v3/ext/...`

5) React bridge rebuild
- Полный `npm run build` всё ещё падает из-за старых не связанных с темами TypeScript-ошибок в Arcade / bridgeI18n
- Но bridge всё равно реально пересобран через прямой `vite build` (без tsc gate)
- Новый `dist` синхронизирован в `Backend/public/bridge/`
- В `public/bridge/index.html` уже прописаны новые hash-файлы
- В новом bridge bundle уже есть canonical `ext_free_01` и актуальный legacy-shell bundle

Что важно понимать честно

`npm run build` сейчас НЕ является зелёным smoke-check из-за старых ошибок вне темы/обоев.
Это не новая поломка от этой сессии, а уже существующий мусор в:
- `src/bridgeI18n.ts`
- `src/features/arcade/*`
- части arcade modules / runtimeAdapter / storage

То есть:
- тема/обои и bridge-layer обновлены
- но общий строгий TypeScript gate проекта всё ещё требует отдельной ревизии позже
