WHAT WAS FIXED IN THIS PACK

1) SITE SESSION RESET NOW REALLY LOGS OUT
- public/app.js
- frontend/src/legacy/legacyApp.ts

Changes:
- Regular Connect now uses normal /api/user/init with { handle, ref } only.
- Removed devReset from the normal Connect flow, so @handle connect is no longer forced through the localhost reset path.
- Local reset no longer auto re-logs the same handle on localhost.
- Reset now really clears site session and shows "Session cleared.".
- Added explicit logout marker: gmx_ext_force_logout.
- Site now sends immediate GMX_SYNC_NOW after connect and reset.

Why:
- Fixes the broken behavior where "Local reset" still looked connected.
- Fixes site/extension session drift after reset.

2) EXTENSION SESSION PERSISTENCE IS STRONGER
- extension/site_sync.js
- extension/background.js
- extension/popup.js

Changes:
- site_sync now honors gmx_ext_force_logout and clears extension local handle/token when the site explicitly resets.
- background hotkeys now read session (handle/token/apiBase) from chrome.storage.local, not sync.
- popup connect now stores sessionUpdatedAt together with handle/token.

Why:
- Fixes the real fail where popup connect could work, but background/hotkeys behaved like the user was logged out after closing the popup.
- Keeps session consistent between site and extension.

3) I18N HTML BUG FIXED
- public/app.js
- frontend/src/legacy/legacyApp.ts

Changes:
- setText() now safely renders small translated HTML tags (b/strong/em/span/kbd/code/br) through the existing sanitizer.
- Strings that already contain <b>...</b> no longer show raw markup in the UI.
- HTML: prefix still works.

Why:
- Fixes the visible translation bug where users saw literal markup like <b>...</b> in text.

4) REACT/VITE SHELL CLEANUP
- frontend/src/LegacyApp.tsx

Changes:
- Removed the always-visible debug overlay ("GMXReply UI loaded / Booting...").
- Error overlay still appears if the legacy boot actually fails.

Why:
- Cleaner product UI.
- No extra debug box on every page load.

5) EXTENSION POPUP KEPT DARK / BLACK
- extension/popup.css

Changes:
- Kept popup black/dark.
- Slightly deepened the black base/card colors without changing layout logic.

6) X TOOLBAR: GM/GN NOW DOCK TO THE REPLY BUTTON CLUSTER
- extension/content.js

Changes:
- Added a new dock-right placement mode.
- GM/GN bar is now mounted relative to the native Reply/Post button cluster itself.
- The bar is positioned absolutely to the LEFT of the native Reply/Post button, instead of trying to live inside the noisy bottom toolbar flow.
- The old layout-breaking wrap behavior should be much lower now.
- Existing rescans/mutation observer remain in place.

Why:
- Fixes the repeated issue where GM/GN dropped into the wrong row or floated with the media/file icons instead of staying near Reply.
