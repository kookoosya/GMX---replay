What was fixed in this pass
1) Site connect crash fixed
- Added a real isLocalDevHost() helper back into public/app.js and frontend/src/legacy/legacyApp.ts.
- This removes the runtime connect error: isLocalDevHost is not defined.
- Local dev reset logic now works only on localhost / 127.0.0.1 again.

2) Site translations restored inside the Vite legacy shell
- frontend/src/LegacyApp.tsx now imports frontend/src/legacy/siteI18nCatalog.ts and exposes it as window.GMX_SITE_I18N before startLegacyApp().
- The legacy runtime inside React/Vite now receives the full multi-language catalog instead of falling back to English-only.
- This fixes the “language switch changes nothing” problem in the Vite site shell.

3) Extension popup returned to a readable dark product look
- extension/popup.css was rebuilt as a dark readable UI again.
- Popup remains English-only (no language switch), but text contrast is stronger and the layout stays wide/readable.

4) X toolbar placement hardened again
- extension/content.js now uses a stronger findActionRowForBox() pass.
- It first tries to lock onto the real composer toolbar / action row, including data-testid=toolBar and wider flex parents that actually contain the native Reply/Post button.
- GM/GN are inserted immediately to the LEFT of Reply/Post in normal layouts.
- If X still reflows the bar vertically, the script retries placement a few times and only then falls back below the box.
- This is safer against small X DOM shifts than the previous brittle row guess.
