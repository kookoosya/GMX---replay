What was changed now
1) extension/content.js
- Fixed the biggest visible extension UX issue on X: inline GM/GN/Best buttons no longer hard-force only one cramped placement next to Reply/Post
- Added adaptive toolbar placement:
  - tries inline placement next to the native Reply/Post button first
  - measures whether the bar is clipped / squeezed / too narrow
  - if X layout clips it, the toolbar falls back to a full-width docked row under the composer instead of leaving a tiny broken sliver
- Added new helper flow:
  - setBarLayout()
  - getDockSlotForBox()
  - barLooksClipped()
  - mountBarInline()
  - mountBarDocked()
- Updated injected inline CSS:
  - supports inline vs dock layouts via data-gmx-layout
  - docked layout wraps cleanly and stretches buttons
  - removed the old brittle single-line-only behavior as the only render mode

2) extension/popup.js
- Added ensurePopupScaffold() so popup can self-heal if popup.html is stale / mismatched / missing required IDs
- If required popup nodes are missing, popup.js now rebuilds a complete usable popup shell in JS and keeps the existing logic working on top of it
- Added updateViewportMode() and resize handling so popup switches into compact stacked mode on narrow widths instead of feeling broken
- Fixed popup theme variable mismatch:
  - --accent2 -> --accent-2
  - this lets the second accent actually apply to the popup skin

3) extension/popup.css
- Reworked popup shell to be more resilient:
  - fluid width instead of hard brittle fixed width
  - safe min/max inline sizing
  - compact mode support
  - better full-width button behavior on narrow popup widths
- Popup background now supports wallpaper via --wall, so popup skin is no longer silently ignoring the synced wallpaper value
- Added a proper fallback logo tile so the popup looks complete even if the static HTML is stale
