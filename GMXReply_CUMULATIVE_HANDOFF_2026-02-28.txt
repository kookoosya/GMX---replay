WHAT WAS DONE IN THIS STEP
1) Legacy-site translations were restored to the full generated catalog.
   - public/i18n/siteI18n.js and frontend/public/i18n/siteI18n.js now come from the richer generated catalog again
   - This restores broad site-language coverage instead of the reduced EN/RU/NL/ID/TR-only helper
   - The app.js translation layer can use createSiteI18nCatalog again, so dynamic text fallback is more reliable across all configured site languages

2) Extra admin translation hooks were added.
   - Core legacy admin labels now have element ids and translated copy overlays for:
     EN, RU, ES, PT, FR, DE, IT, NL, TR, PL, ID
   - The small compatibility wrapper also exposes GMXSiteI18n.apply / force again

3) Legacy admin was simplified.
   - public/app.html removes visible legacy cards for:
     - conversion metrics
     - extension health
   - Remaining visible legacy admin blocks are now centered on:
     - admin sign-in / summary
     - access code generation
     - leaderboard rewards
   - Titles and labels were renamed to be clearer ("Create access codes", "Leaderboard rewards", etc.)

4) Legacy admin self-prunes old clutter even if older HTML is still present.
   - public/app.js was re-added to this cumulative pack
   - It now hides retired admin panels if an older local public/app.html still contains:
     - selector override / history
     - FAQ base
     - extension health
     - conversion metrics
   - This protects against the exact stale-screen problem where old admin blocks were still visible

5) React Admin was simplified further.
   - frontend/src/pages/AdminPage.tsx now hides the extra metrics-heavy summary block and the separate system card
   - The screen is more focused on actions:
     - create codes
     - direct grants
     - leaderboard rewards
     - recent code uses
   - Section labels are clearer and less internal

6) Unused admin FAQ route was retired server-side.
   - index.js now returns 410 admin_faq_retired for:
     - GET /api/admin/faq
     - POST /api/admin/faq
   - This removes dead admin surface that is no longer part of the intended workflow
